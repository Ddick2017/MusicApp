# 🎵 Music — музыкальный плеер для Linux и Windows

Плеер для ваших собственных аудиофайлов: тёмный дизайн, анимированный круг и текст песни, который подсвечивается в такт музыке.

## Возможности

- Играет файлы mp3, flac, ogg, opus, m4a, wav, aac
- Текст песни справа, строки подсвечиваются синхронно с музыкой
- Тексты ищутся автоматически; если нашёлся не тот, версию можно сменить в один клик
- Подстройка текста клавишами, если он идёт чуть раньше или позже песни
- Анимированный чёрно-белый круг, который реагирует на музыку
- Перемешивание без повторов: пока не прозвучат все треки, ни один не повторится
- Запоминает выбранную папку с музыкой

## Установка

Скачайте нужный файл на странице **[Releases](https://github.com/Ddick2017/MusicApp/releases/latest)** (раздел Assets). В названиях файлов вместо `X.Y.Z` стоит номер версии.

| Ваша система | Файл |
|---|---|
| Windows 10 / 11 | `Music-Setup-X.Y.Z.exe` (установщик) или `Music-portable-X.Y.Z.exe` (без установки) |
| Debian, Ubuntu, Linux Mint, Pop!_OS | `musicapp_X.Y.Z_amd64.deb` |
| Fedora, Arch, openSUSE и любые другие Linux | `Music-X.Y.Z.AppImage` |
| Linux без установки | `musicapp-X.Y.Z.tar.gz` |

Программа работает на 64-битных компьютерах (x86_64). Интернет нужен только для скачивания и для поиска текстов песен.

### Windows

1. Скачайте `Music-Setup-X.Y.Z.exe` и запустите его.
2. Windows может показать синее окно «Windows защитила ваш компьютер» (SmartScreen): программа не подписана платным сертификатом издателя. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. Выберите папку установки, после установки найдите **Music** в меню «Пуск».

Версия `Music-portable-X.Y.Z.exe` ничего не устанавливает: просто запустите файл.

### Debian, Ubuntu, Mint (.deb)

Дважды щёлкните по скачанному файлу и нажмите «Установить». Или через терминал (из папки, куда скачали файл, например `~/Загрузки`):

```
cd ~/Загрузки
sudo apt install ./musicapp_*_amd64.deb
```

После установки найдите **Music** в меню приложений или запустите командой `music-player`.

### Любой Linux (AppImage)

1. Скачайте файл `Music-X.Y.Z.AppImage`.
2. Разрешите запуск файла: правый клик → «Свойства» → «Права» → «Разрешить запуск как программы». Или в терминале: `chmod +x Music-*.AppImage`.
3. Запустите двойным щелчком или командой `./Music-*.AppImage`.

Если файл не запускается, установите библиотеку FUSE: `sudo apt install libfuse2t64` (Debian 13, Ubuntu 24.04) или `sudo apt install libfuse2` (более старые версии). Либо запустите без неё: `./Music-*.AppImage --appimage-extract-and-run`.

### Linux без установки (tar.gz)

Распакуйте архив (`tar xzf musicapp-*.tar.gz`) и запустите файл `music-player` внутри папки.

## Первый запуск

Нажмите **«Выбрать папку»** и укажите папку с вашей музыкой. Треки появятся в списке, нажмите на любой, чтобы начать.

## Управление

| Клавиши | Действие |
|---|---|
| Пробел | Пауза / воспроизведение |
| Ctrl + ← / → | Предыдущий / следующий трек |
| `]` и `[` | Текст песни раньше / позже (шаг 0,25 с) |
| Ctrl + F | Сменить текст песни (или кнопка «Сменить текст» справа сверху) |

## Тексты песен

Тексты ищутся автоматически на [lrclib.net](https://lrclib.net) по названию и исполнителю (из тегов или из имени файла). Найденное сохраняется, повторно интернет не нужен.

- **Нашёлся не тот текст.** Нажмите «Сменить текст», при необходимости поправьте название, нажмите «Найти текст» и выберите нужную версию из списка. Кнопка «Авто» возвращает автоматический подбор.
- **Текст идёт не в такт.** Подстройте клавишами `[` и `]`. Для замедленных и ускоренных версий песен программа подгоняет темп текста сама.
- **Свой текст.** Положите рядом с треком файл `.lrc` с таким же именем, как у песни.

Для некоторых песен в базе нет текста: тогда будет пусто или обычный текст без подсветки строк.

## Удаление

- Windows: «Параметры» → «Приложения» → Music → «Удалить» (portable-версию просто удалите).
- Linux `.deb`: `sudo apt remove musicapp`
- AppImage и tar.gz: просто удалите файл или папку.
- Настройки и сохранённые тексты: на Linux папка `musicapp` (или `Music`) внутри `~/.config`, на Windows папка `musicapp` (или `Music`) внутри `%APPDATA%`.

## Сборка из исходников

Нужен Node.js 18 или новее.

```
git clone https://github.com/Ddick2017/MusicApp.git
cd MusicApp
npm install
npm start          # запуск
npm run dist       # сборка для Linux (.deb, AppImage, tar.gz) в папку dist/
npm run dist:win   # сборка для Windows (запускать на Windows)
```

Если нашли ошибку или есть идея, создайте [обращение](https://github.com/Ddick2017/MusicApp/issues/new/choose).
