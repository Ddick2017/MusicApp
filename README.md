# Music — плеер для Linux

Плеер для ваших собственных файлов (mp3, flac, ogg, opus, m4a, wav, aac) с тёмным дизайном, анимированным кругом и синхронизированным текстом песен.

## Установка

Откройте раздел **[Releases](../../releases/latest)** и скачайте файл под свой дистрибутив:

| Дистрибутив | Файл | Как установить |
|---|---|---|
| Debian, Ubuntu, Linux Mint, Pop!_OS | `.deb` | Дважды щёлкните по файлу (откроется установщик) или: `sudo apt install ./musicapp_*_amd64.deb` |
| Fedora, openSUSE, RHEL | `.rpm` | `sudo dnf install ./musicapp-*.x86_64.rpm` |
| Любой дистрибутив | `.AppImage` | `chmod +x Music-*.AppImage`, затем запустите двойным щелчком или `./Music-*.AppImage` |
| Любой дистрибутив | `.tar.gz` | Распакуйте архив и запустите файл `music-player` внутри папки |

Имена файлов зависят от версии. После установки `.deb` или `.rpm` программа **Music** появится в меню приложений, а также запускается командой `music-player`.

Если AppImage не запускается, установите библиотеку FUSE: `sudo apt install libfuse2t64` (Debian 13, Ubuntu 24.04) или `sudo apt install libfuse2` (старше). Либо запустите так: `./Music-*.AppImage --appimage-extract-and-run`.

## Использование

При первом запуске нажмите **«Выбрать папку»** и укажите папку с музыкой.

| Клавиши | Действие |
|---|---|
| Пробел | Пауза / воспроизведение |
| Ctrl + ← / → | Предыдущий / следующий трек |
| `[` и `]` | Сдвинуть текст песни позже / раньше |
| Ctrl + F | Сменить текст песни (или кнопка «Сменить текст») |

Тексты ищутся автоматически на [lrclib.net](https://lrclib.net) (нужен интернет), найденное сохраняется. Можно положить рядом с треком файл `.lrc` с тем же именем.

## Удаление

- `.deb`: `sudo apt remove musicapp`
- `.rpm`: `sudo dnf remove musicapp`
- AppImage и tar.gz: просто удалите файл или папку.
- Настройки и сохранённые тексты: `rm -rf ~/.config/musicapp`

## Сборка из исходников

Нужен Node.js 18 или новее.

```
git clone https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
cd ИМЯ_РЕПОЗИТОРИЯ
npm install
npm start          # запуск
npm run dist       # сборка .deb, .rpm, .AppImage и .tar.gz в папку dist/
```

Установка из исходников с ярлыком в меню: `sh install.sh`.

## Выпуск новой версии (для автора)

Релизы собирает GitHub Actions (файл `.github/workflows/release.yml`). Чтобы выпустить версию, создайте тег:

```
git tag v1.0.0
git push origin v1.0.0
```

Через несколько минут в разделе Releases появятся все файлы.
