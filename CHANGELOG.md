# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии нумеруются по [SemVer](https://semver.org/lang/ru/).

## [1.1.1] — 2026-11-07

### Исправлено
- Windows: установщик теперь «в один клик» и ставит программу только для текущего пользователя (без запроса прав администратора), раньше он мог закрываться, ничего не установив
- Кнопки «назад», «пауза», «вперёд» нарисованы значками и выглядят одинаково на Linux и Windows (раньше в Windows были цветные эмодзи)

## [1.1.0] — 2026-11-07

### Добавлено
- Версия для Windows 10 / 11: установщик и portable-файл (автоматическая сборка на GitHub)

### Исправлено
- Чёрный экран при запуске установленной версии на Linux (ошибка про `/dev/shm`): программа теперь запускается без песочницы Chromium, как и при запуске из исходников

### Изменено
- Пути к файлам теперь обрабатываются одинаково на Linux и Windows

## [1.0.0] — 2026-11-07

Первая версия.

### Добавлено
- Воспроизведение mp3, flac, ogg, opus, m4a, wav, aac из выбранной папки (папка запоминается)
- Тёмный интерфейс: размытый фон из обложки трека, «стеклянные» карточки, лёгкий снег
- Анимированный чёрно-белый круг, который реагирует на музыку
- Синхронизированный текст песни: автоматический поиск на lrclib.net, подсветка текущей строки
- Подгонка текста под темп замедленных и ускоренных версий песен
- Смена текста вручную (выбор из списка версий), кнопка «Авто», подстройка клавишами `[` и `]`
- Перемешивание без повторов, кнопка «назад» помнит историю
- Перемотка по полосе прогресса
- Сборки для Linux: `.deb`, `AppImage`, `tar.gz`
